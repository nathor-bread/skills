# 信息卡布局规范（v22 已验证参数）

底部信息卡位于海报下方蓝带之上。以下为 848×1200 画布下验证过的坐标，可直接复用或按比例迁移。

## 画布与蓝带
| 项 | 值 |
|---|---|
| 画布 W×H | 848 × 1200 |
| 蓝带起始 BLUE_Y | 1035 |
| 蓝带色 BLUE | (139, 211, 221) |

## 信息卡
| 项 | 值 |
|---|---|
| 卡片位置 CARD_X,Y | 40, 985 |
| 卡片尺寸 W×H | 768 × 185 |
| 圆角 | 20 |
| 卡片底色 CARD_BG | (248, 244, 236) 米白 |
| 内边距 padding | 32 |
| 阴影 | 极淡黑 25/255 + 高斯模糊 4 |

## 三行文字 + 图标
左对齐，每行左侧一个统一 24×24 几何图标，图标中心与文字垂直中心对齐。

| 行 | 示例文案 | 字号 | 颜色 | 图标 |
|---|---|---|---|---|
| 1 时间 | 8月1日 10:00-12:00 | 30 | (26,26,26) | clock |
| 2 地点 | 南岸区下浩老街•浩阅书店2楼 | 26 | (51,51,51) | pin |
| 3 费用 | 会员20 / 非会员50 / 亲子套餐65（限额12人） | 22 | (139,105,20) | yen |

- 行间距：36（行1→2）、32（行2→3）。
- 图标外框统一 24×24，2px 线宽，颜色 ICON_COLOR=(139,105,20) 金棕。
- 文字区左缘 text_x = CARD_X + padding + 12 + 14 = 110。

## 二维码位
- 边长 QR_SIZE = 130。
- 位置：卡片右侧，`qr_x = CARD_X + CARD_W - padding - QR_SIZE`（≈646）。
- 先画 12px 圆角米白底衬 (252,250,246)，再贴等比缩放并居中裁剪的二维码。
