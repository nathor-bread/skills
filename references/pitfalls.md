# 踩坑记录 · Pitfalls（实战沉淀）

> 来自 2026-08-04 第一期招募海报 7 轮迭代实战。新踩坑请追加。

## 1. 真实模板平台反爬 → 走路线 B
- **现象**：稿定 gaoding.com / gaoding.art 对 WebFetch 与 agent-browser（真实 Chromium）均返回 **405**；Canva 触发 **Cloudflare 人机验证**。
- **结论**：两大模板平台程序化访问全被拦，**无法自动下载真实设计师模板**。
- **应对**：默认走 **路线 B（从零 PIL 全内容渲染）**；底板用 Pexels 免费可商用直链或 ImageGen 生成。

## 2. ImageGen 出图尺寸 ≠ 请求尺寸
- **现象**：请求 848×1200，实际出图 **832×1216**，导致后续 resize/合成尺寸不匹配报错。
- **应对**：脚本一律 `base.resize((W,H), LANCZOS)` 归一化到目标尺寸，不依赖生成尺寸。

## 3. <28px 字号是海报"显廉价"头号原因
- **现象**：初期徽标 20px、价值点 27px、费用 22px、序号 18px 全部低于 28px，海报观感廉价。
- **规则**：**Ardot 28px 硬底线**——所有文字节点（含页脚/元信息/费用/序号）默认 ≥28px（短边 ≥720px 时不降）。
- **唯一例外**：用户**明确指定**缩小的装饰性系列徽标（微标签），在 selfcheck 中仅告警不中止。
- **自检**：渲染前断言 `core = [各字号]; assert all(s>=28 for s in core)`。

## 4. 文字与二维码重叠
- **现象**：信息卡长费用行右缘侵入二维码区。
- **应对**：`selfcheck` 计算 `text_right_edge = text_x + max(line_w)` 与 `qr_left_edge` 对比；二维码位置自适应（检测文字右缘后缩放/重定位）；长文案截断或减小字号（不低于 28px）。

## 5. 主题字面化搜索偏差
- **现象**：把《AI创作魔法 让灵感自由流动》误解为"读书会"，搜了书本/书桌/笔/纸类素材，用户判定方向错误。
- **正确**：按**主题内核意象**搜——"灵感自由流动"→ 墨水在水中扩散 / 水彩晕染 / 暖色光斑星火，而非字面符号。
- **方法**：先读主题方案 md 提炼内核，再分意象线（流动/晕染/光感）并行搜 Pexels，每线 5–6 张。

## 6. 字体无差异化 → 层次 flat
- **现象**：主副标题/金句同用雅黑，视觉层次拉不开。
- **应对**：主标题 粗雅黑 / 副标题 雅黑 / 金句 **楷体 + 艺术字**，制造明确记忆点。

## 7. 金句艺术字实现要点
- 渐变填充用「字形遮罩合成」：先画描边实心轮廓垫底，再以 `textbbox` 生成的 mask 把渐变图 `putalpha` 合成到字形内部，描边外圈保留。
- 投影阴影单独建层 GaussianBlur，**不要**直接画在文字层上，否则阴影会糊住字形。
- 引号标记同步艺术字处理，视觉统一。

## 8. 双模式配色漏切换
- **现象**：深底图用深字，金句/标题看不清。
- **应对**：`detect_mode()` 按亮度自动选 `light`/`dark` 配色板；金句描边色也随模式切换（浅底深蓝绿描边 / 深底浅金描边）。
